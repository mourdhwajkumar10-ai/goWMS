# S-023: Wrong Quantity on Label

## Scenario Overview

| Field | Value |
|-------|-------|
| **Scenario ID** | S-023 |
| **Category** | Quantity Discrepancies (2.5) |
| **Real-world Context** | Box label says "Qty: 20" but actually contains 18 or 22. |
| **Spec Reference** | Section 14 — Shortage; Section 15 — Excess |
| **Evidence Files** | None — Not yet tested |

## Expected Behavior

1. Box scanned → Label qty shown
2. Physical count differs → Discrepancy
3. Shortage or excess exception created
4. LABEL_MISMATCH event logged
